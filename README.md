# Xpider-Loadingscreen
xpider-Loadingscreen is a simple yet powerful FiveM loading screen that supports music, videos, and full customization to match your server’s style.
It’s designed for easy setup and configuration, letting you control everything — from the logo to the number of songs — directly in your settings.

✨ Features

🎶 Music Support
Add any number of songs using .mp3 files.
Songs will automatically play during the loading screen.

🎬 Video Backgrounds
Use .webm video files to create a cinematic loading experience.

🖼️ Image Background Option
Prefer a simple layout? You can use an image instead of a video background.

🧩 Custom Logo
Replace the default logo with your own server or community logo.

📝 On-Screen Description
Display your own message or server description directly on the loading screen.

⚙️ Configurable Options
All key elements — logo, songs, video/image, description, and more — can be edited in the configuration file.
